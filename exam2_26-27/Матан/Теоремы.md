### 1.1 Признак сравнения для рядов
знакопостоянные ряды,   для любых n   0 <= an <= bn
sum b сход => sum a сход
sum a расход => sum b расход
##### докво: представить как частичные суммы
### 1.2 Признак асимптотический 
an >= 0  bn = an + o(an)  при n -> oo   
=> sum a  и  sum b   сход\расход вместе
##### докво:
	bn = an + t * an    t -> 0  при n -> oo
	сущ N   при любых n >= N    | t | < 1/2
	0 <= an/2 <= bn <= an(1 + t) <= 3/2 * an
### 2. Телескопический признак Коши
sum a_n <=> sum 2^k * a_2^k 
##### докво:
	an -> 0     a_2^k + .... + a_(2^(k+1) - 1) <= 2^k * a_2^k
	sum an <= sum 2^k * a_2^k
	a_(2^(k-1) + 1) + ... + a_2^k >= 2^(k-1) * a_2^k 
	sum an >= sum 2^(k-1) * a_2^k 
### 3. Признак Жамэ
an >= 0     (an)^1/n = 1 - (ln n)/n * Jn
lim Jn     >1 сход    <1 расход
##### докво:
	пусть lim Jn = p < 1           c -> 0
	(an)^1/n = 1 - p * (ln n)/n - c * (ln n)/n      p < q < 1
	(1/n^q)^1/n = n^(-q/n) = e^(-q * ln n/n) = 1 - q * (ln n)/n + b*(ln n)/n  b -> 0
	p < q =>  -p - c > -q + b 
	an > 1/n^q 
### 4. Признак Раабэ
an >= 0    a_n/a_(n+1) = 1 + Rn 
lim Rn    >1 сход      <1 расход
##### докво: p > q > 1      аналогично как в признаке жамэ
### 5. Признак Вейерштрасса мажорантный
|an| <= bn      sum b сход => sum a сход
##### докво: через критерий коши
### 6.1. Признак Дирихле
an -> 0 и монотонна     и   | sum b | <= B
=> sum ab сход
##### докво:
	пусть an >= 0
	| sum{k=m ; till n} bk | <= | sum{k=1 ; n} bk  - sum{k=1 ; m-1} bk | <= 2B
	| sum ab | <= 2Bam < 2Be 
### 6.2. Признак Абеля
an - огр и монотонна    и  sum b сход
=> sum ab сход
##### докво:
	A = lim an
	sum ab = sum (a - A + A)b = sum (a - A)b + A * sum b   
	оба сход (первый по дирихле)
### 7. Формула Коши-Адамара
sum an * x^n     R = 1/lim sup (an)^1/n
|x| < R  сход        |x| > R расход
##### докво:
		lim (an x^n)^1/n  = |x| lim (an)^1/n       (далее радикальный признак коши)

### 9. Теорема о перестановках абсолютно сходящегося ряда
любая перестановка сходится к одной и той же сумме
докво:
	M(n) = max{ б(1), ... ,б(n) }      среди a1 .... a_M(n)  есть все полученные перестановкой
	sum | a_б(n) | <= sum{k =1 ; M(n) } | ak | <= sum an
	L(n) = max{ б^-1(1), ... , б^-1(n) }     сущ N >= L(n)  
	sum{k=1 ; N} a_б(k)    содерж все a1 .... an
	| sum{k=1 ; N} a_б(k) - sum{k=1 ; n} ak | < e   
### 10. Теорема Римана о перестановках
sum a сход условно => для любого числа найдется такая перестановка что ряд будет к нему сходится
##### докво:
	qi >= 0 <= pi    полож и отр слагаемые     sum p и sum q оба расход
	сущ m1 :  c <= A1 = q1 + ... + qm1 <= c + qm1
	сущ n1  :  B1 = A1 - p1 - ... - pn1      c - pn1 <= B1 < c
	далее по индукции получится ряд q1 + ... + qm1 - p1 - ... - pn1 ....
	Ak -> c <- Bk    при k -> oo
### 11. Признак Вейерштрасса равномерной сходимости
| fn(x) | <= bn   для любых x и n
и  sum b сход           =>   sum fn(x) сход равномерно
##### докво:
	sum fn(x) сход по мажорантному признаку
	| sum fn(x) - sum{n=1 ; N} fn(x) | <= | sum{n= N+1 ; oo} fn(x) | <= sum{n = N+1; oo} bn -> 0
	|| F - sum fn || -> 0 
### 12. Признак Дирихле равномерной сходимости
fn(x) монотонна   и  fn --> 0   и  | sum gn(x) | <= C
=> sum fn(x)gn(x) сход равномерно
##### докво:
	по коши сущ N  :  | fn(x) | < e
	| sum{k=m ; oo} fg | <= C(|fm| + |fn| + | sum{k=m+1 ; n-1} f_k+1 - fk |) <= 2C(|fm| + |fn|) <= 4Ce
### 13. Теорема о перестановке предела
fn --> f     сущ an = lim{x->x0} fn(x)
=> lim{n->oo}lim{x->x0} fn(x) = lim{x->x0}lim{n->oo} fn(x)
( <=> сущ a = lim an  <=>  сущ lim{x->x0} f(x) )
докво:
	1) a = lim{x->x0} f(x)
		|an -a | <= | an - fn(x)| + |fn(x) - f(x) | + | f(x) - a | -> 0
	2) a = lim an
		|| fn - f || < e          | an - a | < e
		| f(x) - a | <= |f(x) - fN(x)| + | fN(x) - aN |  + | aN - a| <= 3e

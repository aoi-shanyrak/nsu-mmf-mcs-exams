### 2. Теорема о кольце с однозначным разложением (6)
P - поле => P[x] - кольцо с одн. разлож.
докво:
	1) сущ. разлож.
		f - ненул обрат.
		если неразложим => готово
		иначе: 
		f = f1 * f2    deg f1 < deg f  => конечный процесс
	2) единственность
		f = p1...pr = q1...qs
		индукция: при r = 1 верно
		при r > 1:
		p1 | q1....qs   p1 | qi или (p1, qi) = 1
		перенумеруем p1 | q1  q1 = p1 * e1
		p2....pr = e1q2....qs  
### 3. Кольцо многочленов как кольцо главных идеалов
(f) = {fg | g в P[x]} - главный идеал
докво:
	I = (0) = {0}
	пусть I != (0) => f в I  deg f наим
	(f) c= I:  g в I  g = fq + r,  r = 0 (иначе противоречие)
		=> g = fq => I = (f) 
### 4. Теорема Гильберта (11)
K - Max => K[x] - Max

	=> f(i+1) в I\(f0...fi)      ni = deg fi   ai = старш коэф fi

	a(i+1) = a1b1 + .... + aibi
	g(x) = f(i+1)(x) - комбинации для зануления старшего коэф 
	deg g < n(i+1)             противоречие

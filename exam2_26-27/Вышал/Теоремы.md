### 2. Теорема о кольце с однозначным разложением (6)
P - поле => P[x] - кольцо с одн. разлож.
докво:
	1) сущ. разлож.
		f - ненул обрат.
		если неразложим => готово
		иначе: 
		f = f1 * f2    deg f1 < deg f  => конечный процесс
	2) единственность
		f = p1...pr = q1...qs
		индукция: при r = 1 верно
		при r > 1:
		p1 | q1....qs   p1 | qi или (p1, qi) = 1
		перенумеруем p1 | q1  q1 = p1 * e1
		p2....pr = e1q2....qs

### 4. Теорема Гильберта (11)

### 5. Теорема о существовании корня (12-13)
для любого поле P и неразложимого f из P[x]  deg f > 0   сущ поле L со св-вами 1-3
1) P c= L как подполе
2) a в L   f(a) = 0
3)  подполе в L порожденное P и a совпадает с L => L единственно до изоморфизма
докво:
	1) существование
		L' = P[x]/(f)    (проверить что поле)
		P' = {a + (f) | a в P} 
		построим изоморфизм (проверить)
		L = (L'\P')U P  + переопределить операции
	2) единственность
		пусть для M выполнены условия 1-3
		M1 = {g(b) | g в P[x]} 
		M1 c= M    (проверить сложение и умножение)
		(пояснения) (f, g) = 1 => u(b)f(b) + v(b)g(b) = 1 = v(b)g(b) => сущ обратного
		=> M1 - поле => M = M1
		докажем изоморфизм M и L' ( g + (f) -> g(b)) (проверка 5 свойств)
